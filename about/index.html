我会写什么

公开内容会更偏向 GitHub skills、医学科研工具、生信代码、公众号文章精选、写作方法和可复用的项目记录。内容不会追求"全部都写"，只保留值得长期翻看的部分。

我不会公开什么

默认不放手机号、住址、工作单位细节、私人邮箱、证件信息、公众号后台链接、登录凭据，也不放不必要的生活照片或敏感位置数据。站点只保留公开可分享的信息。

怎么联系

如果你确实需要联系我，优先从 GitHub 主页开始，或者通过仓库的公开入口留下消息。这样最稳，也最符合这个站点的公开边界。

公开站点最重要的不是把信息塞满，而是知道哪些信息应该被留下，哪些信息应该被收起来。

# sushuqiong.github.io

个人主页 + 博客的 GitHub Pages 站点。

## 结构

- `index.html` 首页
- `posts/` 文章列表和文章页
- `archives/` 归档页
- `projects/` 项目页
- `about/` 关于页
- `assets/` 样式、脚本和站点图标

## 发布

1. 仓库名使用 `sushuqiong.github.io`
2. 在 GitHub Pages 中启用 `GitHub Actions`
3. 推送到 `main`

## 本地预览

```bash
cd work/sushuqiong.github.io
python -m http.server 8000
```

然后访问 `http://127.0.0.1:8000/`

## 隐私

站点默认只公开可分享的内容，不放手机号、住址、单位地址或其他敏感信息。

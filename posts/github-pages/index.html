为什么我选择 GitHub Pages 做个人站

传统建站要处理服务器、程序、域名、SSL 和 DNS。GitHub Pages 把这些繁琐步骤尽量收起来，适合先把一个个人站快速搭起来，再慢慢补内容。

5 分钟阅读 · 2026-08-07 · 公开文章

对一个个人站来说，最重要的不是一上来把功能做满，而是先让内容能够稳定公开、稳定访问、稳定更新。GitHub Pages 正好适合这个目标。

它解决了什么

  • 不用自己租服务器，也不用自己维护运行中的 Web 程序。
  • 不用从零配置域名、SSL 和部署脚本。
  • 静态页面一旦准备好，发布流程就可以尽量自动化。

为什么适合个人博客

个人博客往往以文章、归档和少量项目展示为主，不需要复杂的后端。静态站更轻，更容易备份，也更适合长期维护。

适合的场景 个人主页、公开笔记、项目展示、写作归档、课程笔记。

我会怎么用它

这个站点会保留首页、文章页、归档页、项目页和关于页。页面内容保持轻量，重点放在阅读顺畅和后续补充方便上。

对隐私的处理

公开站点只放可以分享的内容，不放手机号、住址、单位地址和其他敏感信息。联系方式也尽量收口到 GitHub 主页，减少不必要的暴露面。

GitHub Pages 的价值，不只是免费，而是把“能不能发出来”这件事变得很简单。
